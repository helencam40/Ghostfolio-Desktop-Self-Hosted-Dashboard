This happens sometimes with new downloads. Simply:
- Click the warning icon in your browser
- Select **"Keep"** or **"Allow"**
- Confirm you want to download the file

### Windows shows "Windows protected your PC"
This is a standard security warning for downloaded applications:
- Click **"More info"**
- Then click **"Run anyway"**
- This happens because the app isn't from the Microsoft Store

### Nothing happens when I click the file
Make sure you're double-clicking the correct file you just downloaded. If it still doesn't work:
- Right-click the file
- Select **"Run as administrator"**
